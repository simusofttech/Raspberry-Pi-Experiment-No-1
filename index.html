Raspberry Pi Experiment No. 1

Push Button Controlled LED

Aim Components Connections Working Procedure Code Output

Aim

To interface a push button and LED with Raspberry Pi and toggle the LED ON and OFF whenever the push button is pressed.

About the Experiment

This experiment demonstrates how digital input and digital output can be controlled using the GPIO pins of a Raspberry Pi.

A push button is used as the digital input and an LED is used as the digital output.

The LED is connected to GPIO17, while the push button is connected to GPIO27.

Whenever the push button is pressed, the program detects the button event and toggles the current state of the LED.

Working

The Raspberry Pi continuously waits for the push button connected to GPIO27 to be pressed.

When the push button is pressed, the pressed() function is called.

Inside this function, the command:

led.toggle()

changes the current state of the LED.

LED OFF Pressed LED ON
LED ON Pressed LED OFF

Procedure

  1. Connect the LED to GPIO17 through a current-limiting resistor.
  2. Connect the other side of the LED circuit to GND.
  3. Connect the push button to GPIO27.
  4. Connect the other side of the push button to GND.
  5. Power ON the Raspberry Pi.
  6. Open the Raspberry Pi terminal.
  7. Create the Python program.
  8. Run the Python program.
  9. Press the push button.
  10. Observe the LED changing between ON and OFF.

Python Code

experiment1.py 
from gpiozero import LED, Button
from signal import pause

led = LED(17)
button = Button(27)

def pressed():
    print("Button Pressed! LED Toggled")
    led.toggle()

button.when_pressed = pressed

print("Ready... Press button to toggle LED")

pause()
Note: GPIO17 is used for the LED and GPIO27 is used for the push button.

Code Explanation

Import gpiozero

from gpiozero import LED, Button

Imports the LED and Button classes required for controlling Raspberry Pi GPIO.

LED GPIO

Creates an LED object connected to GPIO17.

Button GPIO

button = Button(27)

Creates a push button object connected to GPIO27.

Toggle LED

led.toggle()

Changes the LED from ON to OFF or from OFF to ON.

Button Event

button.when_pressed = pressed

Calls the pressed function whenever the button is pressed.

Keep Program Running

pause()

Keeps the Python program running so that it can continuously detect button presses.
